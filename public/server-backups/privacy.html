Naxe Server Backups

Privacy policy

Effective October 11, 2026

Naxe Server Backups is a personal-use application operated by Aladdin Ali for backups of owner-controlled computers.

Google Drive access

The app requests Google Drive permission to read, create, update, and delete files. This permission can cover all files in the authorized Drive account; it is not a Google-enforced restriction to a backup folder. The configured backup workflow uses that access to store encrypted backup data, inspect and verify the backup repository, and restore files when requested.

Data handling

Restic encrypts backup contents before uploading them to Google Drive. Google stores the resulting encrypted files. OAuth credentials and local operational logs are stored on owner-controlled computers with restricted filesystem access. The app does not sell Google user data, use it for advertising, or use it to train AI models.

Retention and control

Backup data is retained until the owner deletes it through backup maintenance or Google Drive. Local credentials and logs remain until removed by the owner. Access can be revoked in Google Account connections. Revoking access stops future access but does not itself delete existing backups.

Contact

For questions or requests concerning this personal backup application, contact Aladdin.
